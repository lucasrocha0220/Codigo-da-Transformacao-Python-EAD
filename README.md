▶️ Como executar

1. Instale o Python

Tenha o Python 3.x instalado no computador.

Verifique com:

python --version

2. Clone o repositório

git clone https://github.com/lucasrocha0220/Codigo-da-Transformacao-Python-EAD.git

Entre na pasta:

cd Codigo-da-Transformacao-Python-EAD

3. Execute os módulos

Cada módulo possui seus próprios arquivos Python.

Exemplo:

python modulo03/modulo03_calculadora_interativa_lucasrocha.py

Para o projeto final:

python modulo15/projetos_automacao_lucasrocha.py

📦 Dependências

Para os projetos que utilizam bibliotecas externas, instale:

pip install requests pillow flask flask-jwt-extended django

Alguns módulos utilizam apenas bibliotecas que já fazem parte da instalação padrão do Python, como sqlite3, tkinter, json, csv, os, random, math e unittest.
